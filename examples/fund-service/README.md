# Ejemplo API-First: fund-service

Contrato OpenAPI (`crud-spec.yaml`) y criterios de aceptación (`acceptance-criteria.md`) de un servicio de fondos de inversión. Su DDL de ejemplo está comentado en `templates/database-spec.sql`.

No está en el manifiesto. Para generarlo: copia el DDL a `specs/domains/funds.sql`, el contrato a `specs/openapi/funds.yaml`, los criterios a `specs/acceptance/fund-service.md` y añade su línea a `.ai/services.txt`.
