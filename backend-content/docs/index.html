content-service

Dominio Content & Blog · Arquitectura hexagonal · Java 21 + Spring Boot 3 · Database-First (Flyway + JPA validate)

1. Propósito y reglas de negocio

Gestiona todo el contenido editorial del producto:

  • Artículos: CRUD completo. ruta debe cumplir post/<slug>.html; ruta y slug son únicos (409 si se duplican). Origen por defecto github.
  • Comentarios: anidables (padreId), contenido 1–2000 car.; el artículo debe existir (404 si no).
  • Categorías (PK slug) y páginas (PK ruta): alta idempotente con conflicto 409.
  • Colecciones de material: tipo articulos/vocabulario; nombreArchivo debe cumplir <nombre>.pdf; slug y archivo únicos.
  • Recursos descargables: categoría por defecto apuntes; slug único; filtrables por categoría.
  • Frases de subtítulos: subtitleNumber positivo y único por película (UNIQUE movie_slug+subtitle_number).

Errores uniformes { code, message }: BAD_REQUEST (400), RESOURCE_NOT_FOUND (404), RESOURCE_ALREADY_EXISTS (409), INTERNAL_ERROR (500).

3. Catálogo funcional de endpoints (Request / Response)

POST/v1/content/articles

Crea un artículo. 409 si ruta o slug ya existen.

Request

{
  "ruta": "post/mi-post.html",
  "slug": "mi-post",
  "titulo": "Mi post",
  "descripcion": "resumen",
  "html": "<p>cuerpo</p>",
  "urlPublica": "https://blog/mi-post",
  "categoriaSlug": "gramatica",
  "fechaPublicacion": "2026-11-08",
  "nivel": "B2"
}

Response 201

{
  "id": 1, "ruta": "post/mi-post.html",
  "slug": "mi-post", "titulo": "Mi post",
  "origen": "github", "esArticuloIndice": false,
  "actualizadoEn": "2026-11-08T12:00:00Z", ...
}

Errores

400 { "code":"BAD_REQUEST", "message":"ruta must match post/<slug>.html" }
409 { "code":"RESOURCE_ALREADY_EXISTS", "message":"Article with ruta or slug already exists" }
