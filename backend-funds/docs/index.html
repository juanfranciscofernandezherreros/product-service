1. Propósito

fund-service gestiona el ciclo de vida de los fondos de inversión (alta, consulta, actualización y baja), su histórico de valor liquidativo (NAV) y la emisión de órdenes de suscripción y reembolso. El fondo se identifica por su ISIN.

2. Reglas de negocio

  • isin, name, category y currency obligatorios.
  • riskLevel entre 1 y 7; comisiones no negativas.
  • No se permiten dos fondos con el mismo ISIN (→ 409).
  • No se puede eliminar un fondo con posiciones activas (orden ≠ REJECTED) (→ 422).
  • Al emitir una orden se genera orderId, estado inicial PENDING y createdAt.

POST /v1/orders

Request (accountId, isin, operationType, amount obligatorios)

{
  "accountId": "ES91-2100-0000-1234567890",
  "isin": "ES0123456789",
  "operationType": "SUBSCRIPTION",
  "amount": 1000.00,
  "currency": "EUR"
}

Response 201

{
  "orderId": "a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11",
  "status": "PENDING",
  "createdAt": "2026-11-08T10:30:00Z"
}

Respuestas de error { code, message }

400 { "code": "BAD_REQUEST", "message": "riskLevel: must be less than or equal to 7" }
404 { "code": "RESOURCE_NOT_FOUND", "message": "Fund not found with isin: XX" }
409 { "code": "RESOURCE_ALREADY_EXISTS", "message": "A fund already exists with isin: ..." }
422 { "code": "FUND_HAS_ACTIVE_POSITIONS", "message": "..." }
500 { "code": "INTERNAL_ERROR", "message": "Unexpected error" }
