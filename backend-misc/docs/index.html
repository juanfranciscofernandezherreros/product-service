misc-service

Dominio Misc — sugerencias, bitácora de usuario y borradores de writing · Arquitectura hexagonal · Java 21 + Spring Boot 3 · Database-First (Flyway + JPA validate)

1. Propósito y reglas de negocio

Este servicio agrupa tres capacidades transversales del producto:

  • Sugerencias: cualquier persona propone mejoras; una sugerencia nace en estado pendiente y transita a publicada o rechazada. Título 5–100 car., descripción 10–1000 car.
  • Bitácora (por usuario): categorías (nombre 1–60 car.) y anotaciones (contenido 1–10000 car.) que pueden asociarse opcionalmente a una categoría del mismo usuario.
  • Borradores de writing (por usuario): tipo obligatorio (essay, article, review, email_informal, email_formal, report, story), título (por defecto «Mi writing B2») y contenido.

Errores uniformes { code, message }: BAD_REQUEST (400), RESOURCE_NOT_FOUND (404), INTERNAL_ERROR (500).

3. Catálogo funcional de endpoints (Request / Response)

POST/v1/suggestions

Crea una sugerencia (estado inicial pendiente). Validación: título 5–100, descripción 10–1000.

Request

{
  "titulo": "Nueva funcionalidad",
  "descripcion": "Me gustaria exportar en PDF"
}

Response 201

{
  "id": 1,
  "titulo": "Nueva funcionalidad",
  "descripcion": "Me gustaria exportar en PDF",
  "estado": "pendiente",
  "creadoEn": "2026-11-08T12:00:00Z"
}

Error 400

{ "code": "BAD_REQUEST", "message": "titulo: size must be between 5 and 100" }
GET/v1/suggestions/{id}

Obtiene una sugerencia por id.

Request

path: id = 1

Response 200

{
  "id": 1, "titulo": "Nueva funcionalidad",
  "descripcion": "...", "estado": "pendiente",
  "creadoEn": "2026-11-08T12:00:00Z"
}

Error 404

{ "code": "RESOURCE_NOT_FOUND", "message": "Suggestion not found: 99" }
GET/v1/suggestions?estado=&offset=&limit=

Lista paginada con filtro opcional por estado.

Request

query: estado=pendiente (opcional)
       offset=0, limit=20

Response 200

{
  "items": [ { "id":1, "estado":"pendiente", ... } ],
  "total": 1, "offset": 0, "limit": 20
}
PATCH/v1/suggestions/{id}/status

Cambia el estado. Valores: pendiente, publicada, rechazada.

Request

{ "estado": "publicada" }

Response 200

{ "id":1, "estado":"publicada", ... }

Error 400

{ "code": "BAD_REQUEST", "message": "Invalid suggestion status: foo" }
