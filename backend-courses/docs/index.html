courses-service

Dominio Courses · Arquitectura hexagonal · Java 21 + Spring Boot 3 · Database-First (Flyway + JPA validate)

1. Propósito y reglas de negocio

  • Cursos: CRUD completo. nombre obligatorio; activo por defecto true.
  • Unidades: slug único (409 si se duplica); orden por defecto 100, publicado por defecto true. Filtrables por nivel y publicado.
  • Actividades: slug único con patrón ^[a-z0-9][a-z0-9-]{2,99}$; destreza del enum; orden por defecto 1, publicado por defecto false. Filtrables por destreza/publicado (paginado).
  • Preguntas de actividad: orden positivo y único por actividad (409); tipo del enum; media opcional (audio/imagen con URL https). La actividad debe existir (404).
  • Intentos: registran respuestas/detalle (JSON) y contadores no negativos; la actividad debe existir (404).

Errores uniformes { code, message }: BAD_REQUEST (400), RESOURCE_NOT_FOUND (404), RESOURCE_ALREADY_EXISTS (409), INTERNAL_ERROR (500).
