access-service

Documentación Funcional · Roles & Permisos · Java 21 · Hexagonal · Database-First (SDD + Flyway)

ArquitecturaEsquemaEndpointsCalidad

1. Propósito

Gestiona roles, permisos y sus asignaciones (permisos por rol, roles por usuario). El esquema PostgreSQL es la fuente de verdad (Flyway crea, JPA valida).

2. Arquitectura (hexagonal)

3. Modelo de datos (esquema exacto)

TablaColumnas / Claves
rolescodigo VARCHAR(64) PK · descripcion VARCHAR(255) NOT NULL
permisoscodigo VARCHAR(64) PK · descripcion VARCHAR(255) NOT NULL
roles_permisosPK(rol, permiso) · FK rol→roles · FK permiso→permisos (ON DELETE CASCADE)
usuarios_rolesPK(usuario_id, rol) · FK rol→roles · asignado_por UUID · creado_en TIMESTAMPTZ DEFAULT now()

4. Endpoints — Request y Response

MétodoRutaCódigos
POST/v1/access/roles201/400/409
GET/v1/access/roles · /{codigo}200 / 404
DELETE/v1/access/roles/{codigo}204/404
POST/v1/access/roles/{codigo}/permissions201/404
POST/v1/access/permissions201/400/409
POST/v1/access/users/{userId}/roles201/400/404

POST /v1/access/roles — Request

{ "codigo": "ADMIN", "descripcion": "Administrador" }

POST .../users/{id}/roles — Request

{ "rol": "ADMIN", "asignadoPor": null }

Response 201 (rol)

{ "codigo": "ADMIN", "descripcion": "Administrador" }

Response 201 (asignación)

{ "usuarioId": "1111...", "rol": "ADMIN", "asignadoPor": null, "creadoEn": "2026-11-08T10:30:00Z" }

Errores { code, message }

400 { "code": "BAD_REQUEST", "message": "codigo: must not be blank" }
404 { "code": "RESOURCE_NOT_FOUND", "message": "Role not found: X" }
409 { "code": "RESOURCE_ALREADY_EXISTS", "message": "Role already exists: ADMIN" }

5. Calidad

  • JUnit 5 + Mockito, ArchUnit, Cucumber BDD (H2 + Flyway).
  • Checkstyle sin violaciones y JaCoCo ≥ 80%.
