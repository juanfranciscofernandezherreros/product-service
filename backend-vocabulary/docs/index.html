Propósito Arquitectura Esquema Endpoints Calidad

1. Propósito

Gestiona ítems de vocabulario (CRUD) y el progreso de aprendizaje por usuario. Generado en modo Database-First: el esquema PostgreSQL es la fuente de verdad (Flyway crea las tablas, JPA valida).

2. Arquitectura (hexagonal)

3. Modelo de datos (esquema exacto)

Derivado de specs/domains/vocabulary.sql, aplicado por Flyway:

TablaColumnaTipoRestricciones
vocabulary_itemsidBIGINTPK, IDENTITY
enVARCHAR(255)NOT NULL, UNIQUE
esVARCHAR(255)NOT NULL
exampleVARCHAR(2000)—
levelVARCHAR(2)NOT NULL, CHECK IN (A1,A2,B1,B2,C1)
vocabulary_progressuser_idUUIDPK
item_idBIGINTPK, FK→vocabulary_items(id) ON DELETE CASCADE
streakINTEGERNOT NULL, DEFAULT 0, CHECK ≥ 0
last_gradeINTEGERNOT NULL, DEFAULT 0, CHECK 0..2
next_review_atTIMESTAMPTZNOT NULL, DEFAULT now()
first_seen_dayDATENOT NULL, DEFAULT CURRENT_DATE

POST /v1/vocabulary/items

Request (en, es, level obligatorios)

{
  "en": "book",
  "es": "libro",
  "example": "a book",
  "level": "A1"
}

Response 201

{
  "id": 1,
  "en": "book",
  "es": "libro",
  "example": "a book",
  "level": "A1"
}

GET /v1/vocabulary/items · PUT /v1/vocabulary/items/{id}

Request — query level, limit, offset; PUT body:

GET /v1/vocabulary/items?level=A1&limit=20&offset=0
PUT body: { "es": "libro nuevo", "level": "B2" }

Response 200 (lista / ítem)

{ "total": 1, "items": [
  { "id": 1, "en": "book", "es": "libro", "level": "A1" }
] }

PUT /v1/vocabulary/users/{userId}/progress

Request (itemId obligatorio, lastGrade 0..2)

{ "itemId": 1, "streak": 2, "lastGrade": 1 }

Response 200

{
  "userId": "1111...",
  "itemId": 1,
  "streak": 2,
  "lastGrade": 1,
  "nextReviewAt": "2026-11-08T10:30:00Z",
  "firstSeenDay": "2026-11-08"
}

Errores { code, message }

400 { "code": "BAD_REQUEST", "message": "en: must not be blank" }
404 { "code": "RESOURCE_NOT_FOUND", "message": "Vocabulary item not found with id: 9" }
409 { "code": "RESOURCE_ALREADY_EXISTS", "message": "A vocabulary item already exists with en: book" }
500 { "code": "INTERNAL_ERROR", "message": "Unexpected error" }
