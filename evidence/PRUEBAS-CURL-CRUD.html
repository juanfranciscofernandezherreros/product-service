CA-11 — Prueba CRUD completa por endpoint (cURL)

Dado cada microservicio arrancado · Cuando se ejecuta la secuencia cURL de su recurso · Entonces cada endpoint responde con el código y el cuerpo esperados (201/200/204/4xx).

Cómo ejecutar

Prerrequisito: arrancar el servicio con la credencial de Supabase en el entorno (según la política de acceso). El esquema ya existe en Supabase (perfil dev: ddl-auto: none, Flyway off).

# 1) Credencial fuera del repo (ver .env.local / variable de entorno)
export DB_PASS_DEV='********'

# 2) Arrancar el microservicio (en su carpeta)
cd backend-content && mvn spring-boot:run      # puerto 8090

# 3) Ejecutar los cURL de su sección (otra terminal)
Lecturas protegidas por RLS: si el endpoint lee tablas que exigen usuario autenticado, añade la cabecera del usuario: -H "Authorization: Bearer <jwt_del_usuario>" (política REST + JWT). La service_role solo para backend sin usuario, como secreto por variable de entorno.
