1. Propósito

Gestiona perfiles públicos, seguimientos, mensajes privados y solicitudes de mensaje. El esquema PostgreSQL es la fuente de verdad (Flyway crea, JPA valida).

2. Arquitectura (hexagonal)

3. Modelo de datos (esquema exacto)

TablaColumnas / Restricciones
perfiles_publicosuser_id PK · alias UNIQUE · biografia(180) · avatar_emoji · creado_en
seguimientosPK(seguidor,seguido) · CHECK seguidor≠seguido · creado_en
mensajes_privadosid BIGINT IDENTITY PK · remitente · destinatario · CHECK remitente≠destinatario · contenido(2000) · creado_en
solicitudes_mensajeid PK · UNIQUE(remitente,destinatario) · estado CHECK(pendiente/aceptada/rechazada) · mensaje_inicial · creado_en · respondido_en

4. Endpoints — Request y Response

MétodoRuta (base /v1/social)Códigos
POST/public-profiles201/400/409
GET/PUT/public-profiles/{userId}200/404
GET/POST/users/{userId}/following200 · 201
DEL/users/{userId}/following/{seguido}204/404
POST/messages201/400
POST/PUT/message-requests · /{id}201/409 · 200/404

POST /public-profiles — Request

{ "userId":"...","alias":"alice_01",
  "biografia":"Hi","avatarEmoji":"BOOK" }

POST /messages — Request

{ "remitente":"...","destinatario":"...","contenido":"Hola" }

201 (profile)

{ "userId":"...","alias":"alice_01","creadoEn":"...",
  "biografia":"Hi","avatarEmoji":"BOOK" }

201 (message)

{ "id":1,"remitente":"...","destinatario":"...","contenido":"Hola","creadoEn":"..." }

Errores { code, message }

400 BAD_REQUEST · 404 RESOURCE_NOT_FOUND · 409 RESOURCE_ALREADY_EXISTS · 500 INTERNAL_ERROR
