1. Propósito

Gestiona la planificación de estudio B2 por usuario: plan de estudio, plan IA, objetivo semanal, sesiones completadas e informes semanales. El esquema PostgreSQL es la fuente de verdad (Flyway crea, JPA valida).

2. Arquitectura (hexagonal)

3. Modelo de datos (esquema exacto)

TablaColumnas / Restricciones
study_plansuser_id PK · minutos_dia CHECK 10..180 · dias_semana (CSV) · prioridad CHECK(...) · hora_recordatorio TIME · recordatorio_activo · actualizado_en
ai_plansuser_id PK · semanas CHECK IN(4,8,12,16,24) · plan (JSON) · actualizado_en
weekly_goalsuser_id PK · tipo CHECK(unidades/examenes/actividades) · cantidad CHECK 1..20 · actualizado_en
study_sessionsPK(user_id,dia,tarea) · tarea CHECK(...) · completada_en
weekly_reportsPK(user_id,semana_inicio) · semana_fin (≥ inicio) · informe (JSON) · generado_en
